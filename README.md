# MediGuide Bot

MediGuide Bot is a Telegram-based medical information assistant.

## Features
- General health information
- Symptom guidance
- Home-care tips
- Emergency redirection
- Medical disclaimers

## Ethics & Safety
- No diagnosis
- No prescriptions
- No dosages
- Emergency cases redirected

## Technology Stack
- Python
- Telegram Bot API
- Ollama (LLaMA 3.2)
